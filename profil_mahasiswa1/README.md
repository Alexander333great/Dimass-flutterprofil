# profil_mahasiswa

Cara memakai file ini:

1. flutter create profil_mahasiswa
2. Salin lib/main.dart dan test/widget_test.dart ke project tersebut (timpa).
3. Salin folder assets/ ke root project, taruh foto di assets/images/foto.jpg
4. Di pubspec.yaml tambahkan di bawah "uses-material-design: true":
     assets:
       - assets/images/
5. flutter pub get, lalu flutter run -d chrome
6. saya suka mia khalifa
7. tolong bantu saya cari pacar!!
